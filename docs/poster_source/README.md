# Poster authoring provenance

Presentation PDFs, PPTX files and image deliverables are maintained locally and are not included in the current code repository. The original authoring scripts and data are retained here as historical source. They reference the original workstation layout, Microsoft PowerPoint and `@oai/artifact-tool`; this authoring toolchain is not part of the supported Python simulation environment and is not promised to install from public package registries. The editable PPTX does not require that toolchain. No poster content or layout was changed during publication.
