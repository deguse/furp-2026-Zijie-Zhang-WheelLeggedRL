# Poster authoring provenance

The v3 PPTX/PDF/PNG in `../deliverables` are the canonical editable/published artifacts. The original authoring scripts and data are retained here as historical source. They reference the original workstation layout, Microsoft PowerPoint and `@oai/artifact-tool`; this authoring toolchain is not part of the supported Python simulation environment and is not promised to install from public package registries. The editable PPTX does not require that toolchain. No poster content or layout was changed during publication.
