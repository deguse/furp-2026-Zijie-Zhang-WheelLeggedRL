# HopperTrex Hybrid v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a reproducible Hybrid v2 curriculum that combines an identified wheel-balance controller with a fixed six-dimensional residual PPO interface, posture commands, and capability-driven promotion gates without changing legacy Stage0-8 behavior.

**Architecture:** Pure Python modules own stage contracts, action composition, controller identification, posture fitting, and gate decisions. A separate MjLab task module adapts those tested contracts to manager-based action and command terms. The legacy task factory and evaluator retain their public CLI and task registrations.

**Tech Stack:** Python 3.11, dataclasses, NumPy, PyTorch, SciPy, MjLab manager-based environments, RSL-RL, `unittest`.
